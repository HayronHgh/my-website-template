# Markdown 統計圖表

文章、研究、專案說明與 LeetCode 筆記使用同一套 Markdown 渲染器，皆可插入圖表。
後台的區塊編輯工具列可選「柱狀圖／圓餅圖／折線圖」，按「插入圖表」後會建立
可編輯的 `chart` 區塊。點圖表空白處可編輯 JSON；按「查看原始數據」則展開數據表。
和一般文字一樣，必須儲存才會更新網站；不會自動改變文章的公開狀態。

## 最小語法

複製以下完整區塊，將範例資料換成自己的數據：

````markdown
```chart
{
  "type": "bar",
  "title": "每週完成題數",
  "unit": "題",
  "labels": ["第一週", "第二週", "第三週"],
  "series": [{ "name": "完成題數", "values": [8, 12, 16] }]
}
```
````

將 `type` 改成 `line` 就是折線圖，改成 `pie` 就是圓餅圖。不要把 `chart` 寫成 `json`，
後者仍然是一般程式碼區塊，不會產生統計圖。

## 欄位

| 欄位 | 用途與限制 |
| --- | --- |
| `type` | `bar`、`pie`、`line` |
| `title` | 必填，1–120 字元，顯示於圖表標題與數據表 |
| `description` | 選填，最多 500 字元，適合寫資料來源、統計期間、比較條件 |
| `unit` | 選填，最多 20 字元，例如「題」「ms」「人」 |
| `labels` | 1–24 個非空標籤，每個最多 60 字元 |
| `series` | 1–4 組資料；每組有 `name` 與 `values` |
| `series[].name` | 非空資料組名稱，最多 60 字元 |
| `series[].values` | 必須是數字，數量須等於 labels；範圍為 -1e12 至 1e12 |

最多 40,000 字元的 JSON，不支援函式、HTML、外部資料網址、自訂 CSS 或額外欄位。
這些限制避免不安全程式碼與超大型圖表拖慢文章。資料錯誤時會顯示原因和原始設定，
不會讓整篇文章消失。

## 多組比較與資料語意

柱狀圖會並列各組，不堆疊；折線圖每組一條線，使用方形資料點。兩者支援負值、
小數與全零資料，縱軸包含零，避免柱狀長度誤導。折線圖依 labels 的輸入順序連接，
不會自行解析日期或排序，也沒有平滑曲線及插值。

````markdown
```chart
{
  "type": "bar",
  "title": "查詢時間比較",
  "description": "示範資料，請填入相同條件下的實測結果。",
  "unit": "ms",
  "labels": ["100 筆", "1,000 筆", "10,000 筆"],
  "series": [
    { "name": "調整前", "values": [32, 84, 196] },
    { "name": "調整後", "values": [21, 46, 97] }
  ]
}
```
````

圓餅圖只允許 **一組資料**，每項必須非負且合計大於零。百分比由資料合計計算，
顯示到小數第一位；四捨五入後可能不剛好為 100%。單一非零項會顯示完整圓形，
零值項仍保留在圖例與數據表。未填資料不等於零：請自行確認統計口徑後再輸入。

長標籤在圖上縮寫，但完整名稱與原始數值保留於表格。大量分類會讓圖表區域橫向捲動，
不撐開文章或縮小刻度；可用鍵盤聚焦圖表後捲動。圖表使用原生 SVG 和數據表，
關閉 JavaScript 也能閱讀，無第三方圖表請求或追蹤。

## 視覺與維護

使用網站的深藍面板、像素硬邊框、青／紫／金／粉色系列與等寬刻度；無自動播放動畫。
套用位置為 `app/charts.css`，規格與模板在 `lib/content/chart-spec.ts`，
伺服器渲染在 `lib/content/chart-renderer.ts`。清理 Markdown 後才由受控節點產生 SVG，
不接受使用者 SVG 屬性，也不放寬原本的 HTML 清理白名單。

完整示範：[examples/statistical-charts.md](examples/statistical-charts.md)。本機視覺預覽：

```sh
pnpm exec tsx scripts/preview-markdown-charts.ts
```

這只啟動本機示範頁，不會建立或發布正式文章。預覽工具 15 分鐘後會自行停止。
